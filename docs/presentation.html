03 · Data Engineering the input

Smart features beat brute force.

  • 37 static classes. ASL A–Z, digits 0–9, plus fist, peace, OK, thumbs up/down.

  • 4 dynamic classes. Swipe left, swipe right, zoom in, zoom out — 30-frame sequences.

  • Strict hold-out. Augmented training stays separate from a pristine test set — zero leakage.

  • Wrist-relative normalization. Translation and scale invariance before any modelling.

04 · Static head Residual MLP for 37 classes

Deep, but lean.

  • Dense 512 → 256. ReLU, BatchNorm, Dropout 0.25, L2 = 3×10⁻⁴.

  • Residual bottleneck. 256 → 128 → 256, added back to the Block-2 output.

  • Softmax over 37 classes. Adam + cosine-decay LR, label smoothing α = 0.05.

  • Class balance. SMOTE applied conditionally to underrepresented classes.

Training curves — Residual MLP
05 · Dynamic head BiLSTM + Attention for motion

Reading motion, not snapshots.

  • Input 30 × 63. About a second of motion, sampled as landmark coordinates.

  • Bidirectional LSTM. Forward and backward context at every time step.

  • Attention layer. Per-frame weights emphasise the gesture's apex.

  • Softmax over 4 motions. Rapid convergence, no overfit on pristine sequences.

06 · Runtime Where ML meets UX

Deep nets classify. Physics control.

The classifier produces predictions, but the user experience comes from the runtime layer that smooths, gates, and converts those predictions into actions.

01 · Stability

Holds & cooldowns

  • Confidence > 0.85 required to fire.

  • Gesture must persist over a hold window.

  • Removes one-frame jitter entirely.

02 · Pinch zoom

Physics heuristic

  • 16-frame deque of thumb–index distance.

  • Max-min spread Δ > 0.07 fires the event.

  • Sub-second response — no 30-frame wait.

03 · Multi-hand

State machine

  • Independent state per hand.

  • Conflict resolution: left vs right.

  • Special phrases trigger UI overlays.

09 · Wrap-up What we built, what's next

Three lessons, three directions.

TAKEAWAYS

  • Feature engineering still pays. Pairwise distances unlock 4+ accuracy points over a strong MLP alone.

  • Bidirectional context wins. BiLSTM + Attention beat every simpler temporal net we tried.

  • Hybrid beats end-to-end for UX. Deep nets for classes, physics for control — zero latency on zoom.

WHAT'S NEXT

  • Continuous sign language. Move from isolated gestures to streamed sentence-level translation.

  • Edge deployment. TensorFlow Lite quantization for mobile and embedded targets.

  • Personalisation. Per-user fine-tuning for individual signing styles and speeds.
